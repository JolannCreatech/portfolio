The project

whisPER is a messaging application where messages are end-to-end encrypted and the service runs on a Raspberry Pi at home rather than on a hosted platform. The backend is written in Rust with a SQL database, and the client is a Swift application.

The stack

A server at home

The application is self-hosted: the server and its database run on a Raspberry Pi at home rather than on a hosted platform, and the Swift application is the client.
